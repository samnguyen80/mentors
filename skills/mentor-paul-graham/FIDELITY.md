## Test design

- 3 known-stance questions (topics on which the person has repeatedly made public statements) + 1 out-of-scope question (the person has not stated a definite view, testing honest inference) + 1 style-sample question
- The answering agent reads only this skill's directory files and is forbidden from going online; the grading agent runs independently and judges against PG's real public stances
- Basis: the SkillLens paper (arXiv 2605.23899) empirically found LLM self-evaluation accuracy of only 46.4%, so answering and grading are strictly separated
