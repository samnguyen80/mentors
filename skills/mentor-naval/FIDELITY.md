## Test design

- 3 known-position questions (topics the person has stated publicly and repeatedly) + 1 out-of-scope question (never discussed systematically by the person; tests honest inference) + 1 style-sample question
- The answering agent read only files in this skill's directory and was forbidden from browsing the web; the scoring agent ran independently and judged against Naval's real public positions
- Basis: the SkillLens paper (arXiv 2605.23899) empirically found LLM self-evaluation accuracy of only 46.4%, so answering and scoring are strictly separated
