# Methodology for distilling a thinking framework

> From raw information to a working mental model: the core method

## I. The three-layer test for identifying a mental model

A claim is accepted as a "mental model" (rather than an offhand remark) only when it passes all three layers of the test:

### Test 1: Cross-domain recurrence
The same thinking framework shows up in at least 2 different domains that the person discusses.

For example, Naval's concept of "leverage":
- Discusses leverage in creating wealth (code, media, capital, labor)
- Discusses leverage in personal development (specific knowledge + leverage = compounding)
- Discusses leverage in choosing a career (pick work that carries a leverage effect)
→ Recurs in 3 domains → this is a real mental model

### Test 2: Generative power
Using the model, you can infer the person's likely position on a new problem.

For example, if Munger's "inversion" is a mental model:
- Faced with "how do I succeed" → he would first think "how would I be sure to fail"
- Faced with "how should I invest" → he would first think "how would I lose all my money"
→ It generates new inferences → this is a real mental model

### Test 3: Exclusivity
Not every smart person thinks this way; the model reflects the person's own point of view.

For example: "antifragile" is Taleb's; not everyone sees the world that way
→ It discriminates → this is a model worth distilling

**If a viewpoint passes only 1 layer** → demote it to a "decision principle" (heuristic), not a mental model.
**If a viewpoint passes no layer** → it may only be something the person said in one particular situation; leave it out.

## II. Quantifying the expression DNA

### 2.1 Sentence fingerprint

From the person's long writings or talks, pick 20 passages at random and tally:

| Dimension | How to measure |
|-----------|----------------|
| Average sentence length | number of words / number of sentences |
| Question ratio | number of questions / total sentences |
| Analogy density | number of analogies / 1000 words |
| First-person usage | frequency of "I" |
| Certainty ratio | "definitely", "obviously" versus "perhaps", "maybe" |
| Transition frequency | "but", "however", "yet" / 1000 words |

### 2.2 Style labels

Label along the following axes:

```
Formal ←→ Colloquial
Abstract ←→ Concrete
Cautious ←→ Assertive
Academic ←→ Popular
Long sentences ←→ Short sentences
Build-up first ←→ Conclusion first
Data-driven ←→ Story-driven
```

### 2.3 Taboo words and catchphrases

- Words the person never uses → do not use them when generating the skill either
- The person's catchphrases and recurring ways of putting things → use in moderation (too many turns into parody)

## III. Principles for handling contradictions

Contradiction is a core feature of a personality, not a bug to fix.

### Three kinds of contradiction

1. **Contradiction over time** (evolving views)
   - Early on the person said A, later said B
   - Handling: record the trajectory of evolution, mark the "early phase" and "recent"
   - In the skill, take the "recent view" as the main one, but mention the evolution

2. **Contradiction across domains** (different rules in different contexts)
   - At work the person advocates X, in life advocates Y
   - Handling: record by domain, do not force unity
   - This is exactly where depth comes from

3. **Essential tension** (inner conflict between values)
   - For example: pursuing freedom while also valuing discipline
   - Handling: label it explicitly as a "core tension"
   - This is often the most interesting part of the person

### The wrong ways to handle it
- Choosing one side and ignoring the other
- Inventing a reconciling explanation
- Pretending the contradiction does not exist

## IV. When information is insufficient

| Situation | Handling |
|-----------|----------|
| One dimension has very little public information | In the skill, mark "information is lacking; this dimension is speculation" |
| Only secondary information exists | Lower the confidence, write "according to [source] reporting" |
| Information conflicts and cannot be adjudicated | Present both side by side and let the user judge |
| The person deliberately keeps an area private | Respect the boundary, and write in the skill "this person stays silent on this topic" |

---

## V. How a person-based skill differs from a topic-based skill

| Dimension | Person-based skill | Topic-based skill |
|-----------|--------------------|-------------------|
| Core | One person's way of thinking | The thinking toolkit of a field |
| Source of mental models | Mostly from one person | A synthesis of many viewpoints |
| Expression style | Imitates that person | Neutral but professional |
| Handling contradiction | Keeps the individual's internal contradictions | Presents disagreements between schools |
| How to validate | Check against the person's known positions | Check against the field's consensus |

## VI. Quality self-check list

After generating the skill, check yourself with the following questions:

### Mental models
- [ ] Does each model have evidence from at least 2 different domains?
- [ ] Is the number of models between 3 and 7? (too few = shallow, too many = not yet distilled)
- [ ] Does each model have a clear context of application and limits?
- [ ] Is there tension between the models, without contradictions that cancel themselves out?

### Expression DNA
- [ ] Is it recognizable when read aloud, not like a generic AI?
- [ ] Does it avoid imitating so hard that it becomes a caricature?
- [ ] Does it capture the core traits rather than only mimicking the surface?

### Decision principles
- [ ] Does each rule have a concrete example to rest on?
- [ ] Can it be triggered by a new situation (not only correct for the original example)?

### Honest boundaries
- [ ] Does it state plainly what the skill cannot do?
- [ ] Does it record the information sources and the research date?
- [ ] Does it admit the dimensions where information is still lacking?

### Overall
- [ ] Looking at a new problem through this person's eyes, does it yield a valuable perspective?
- [ ] Is it a thinking framework in operation, rather than a stitched-together set of verbatim quotes?
- [ ] With the name removed, can you still recognize whose way of thinking this is?
- [ ] Is there a "The asker" section (Sam, Founder & CEO of Avada Group, Shopify app SaaS; the mentor says "I", replies in the asker's language, and in Vietnamese says "tôi" and calls Sam "anh"), and can the advice be tied to that context?
